# Confirmation of Payee

This repository contains one-page, A4 PDF documents introducing and explaining TechnoXander’s [Confirmation of Payee (CoP)](https://technoxander.com/confirmation-of-payee/) solution for UK banks and payment service providers.

## About the solution

Confirmation of Payee is an account name checking service used for UK payments. Before a transfer is authorised, the service compares the payee name entered by the payer with the account-holder name held for the supplied sort code and account number, returning a Match, Close Match or No Match result. TechnoXander’s Pay.UK-approved solution supports requester and responder capabilities, real-time checks and integration options for participating institutions.
